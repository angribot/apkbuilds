# Extract CI operations behind shell-module seams

Keep workflow YAML responsible for job orchestration, mounts, and explicit
parameters. Build one package-origin family in
`scripts/build-package-family.sh`, sign a merged repository in
`scripts/sign-repository.sh`, and verify a staged repository in
`scripts/verify-repository.sh`. Each module reports its stage, architecture,
and package origin and returns nonzero on an invalid output.

The build module is the only network-capable operation and sees only the
repository public key and an ephemeral build key generated by `abuild`. Merge
validation remains isolated and network-free before signing. The persistent
repository signing key is mounted only into the network-isolated signing
module. Verification is also network-free in CI; its optional installation
mode retains the existing exact-build checks and retries only APK index
acquisition.
