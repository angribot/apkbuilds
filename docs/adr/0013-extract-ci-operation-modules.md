# Extract CI operations behind shell-module seams

Keep workflow YAML responsible for job orchestration, mounts, and explicit
parameters. Build one package-origin family in
`scripts/build-package-family.sh`, sign a merged repository in
`scripts/sign-repository.sh`, and verify a staged repository in
`scripts/verify-repository.sh`. Each module reports its stage, architecture,
and package origin and returns nonzero on an invalid output.

Only the build module executes untrusted upstream build code. It sees only
the repository public key and an ephemeral build key generated by `abuild`.
The build module and optional installation verification retain their existing
network access; merge validation remains isolated and network-free
before signing. The persistent repository signing key is mounted only into the
network-isolated signing module. Signature-only verification is network-free;
the optional installation mode retains the existing network access needed for
Alpine dependencies, exact-build checks, and bounded APK index retries.
